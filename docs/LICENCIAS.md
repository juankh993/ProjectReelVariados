# Registro de licencias — canal educativo

> Toda pieza de material que entre al canal se anota acá con su fuente y licencia.
> **Regla:** si la fuente no está en la lista de permitidas, no se usa.

## Fuentes permitidas

| Fuente | Licencia | Requiere crédito |
|---|---|---|
| NASA / ESA | Dominio público | No (pero se agradece) |
| Pexels | Pexels License | No |
| Pixabay | Pixabay License | No |
| Unsplash | Unsplash License | No |
| Wikimedia Commons | CC0 / CC BY / CC BY-SA | **Sí** (BY y BY-SA) |
| Freesound | Solo CC0 / CC BY | **Sí** (BY) |
| Material propio o de suscriptores | Propia / cesión | No |

## Fuentes prohibidas

- Pinterest / Klickpin
- TikTok
- YouTube de otros canales
- Cualquier cosa sin licencia identificable
- Freesound CC-BY-**NC** (prohíbe uso comercial)
