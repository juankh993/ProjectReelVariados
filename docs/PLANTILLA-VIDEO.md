# Plantilla de descripción de cada video

Copiar y completar. Lo que va acá **no** va en la descripción del canal.

```
[El dato en una línea, sin repetir el título]

Nuevos videos: todos los días.

Fuente: [NASA / ESA / Pexels / Pixabay / Wikimedia Commons]
Material: [autor y licencia, solo si la fuente exige crédito]

¿Cuál te sorprendió más? Dejalo en los comentarios.

#datoneta #shorts #ytshorts #youtubeshorts
```

## Título

```
[Gancho corto] (y no lo sabías) #shorts
```

Máximo ~60 caracteres para que no se corte en el celular.

## Etiquetas

```
datoneta, curiosidades, ciencia, tecnologia, datos curiosos, shorts, educativo
```

## Créditos

- **NASA / ESA / Pexels / Pixabay / Unsplash:** no exigen crédito, pero se agradece.
- **Wikimedia Commons (CC BY / CC BY-SA)** y **Freesound CC BY:** crédito obligatorio
  con autor, obra y licencia. Además se anota en `docs/LICENCIAS.md`.

## Reglas del cierre

- El video termina con una **pregunta** (genera comentarios).
- La descripción cierra con "¿Cuál te sorprendió más? Dejalo en los comentarios."
- No prometer nada que el video no cumpla (clickbait vacío = caída de retención).
